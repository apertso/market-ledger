How the metrics work
Last price & spread
The latest trade price; the current ask minus bid.
Volume & VWAP
Traded units and quantity-weighted price since the run began. Available bid and ask quantities do not add to volume.
Book imbalance
(Bid quantity − ask quantity) / (bid quantity + ask quantity). Positive favors the bid side; negative favors the ask side. A zero denominator is unavailable.
